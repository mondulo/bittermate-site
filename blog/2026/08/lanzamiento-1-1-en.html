Changelog — version 1.1 (2026-08-31)

New features

  • Immediate metadata and cover art search for small imports (under 100 songs)
  • The miniplayer bar that opens Now Playing is now more prominent
  • Alternative view showing the album cover at double size
  • The queue now shows a song count
  • Option to hide play count
  • The optional volume limit now goes up to 75% (previously 60%)
  • Redesigned "About" panel with new user badges and an updated music quote
  • Higher information density in the Statistics panel
  • Usability improvements in the Library panel
  • More light and dark themes. New vibrant themes with bold colors — no more pastels
  • Additional Now Playing style: XL, with a giant cover and buttons on top
  • Alphabet index bar in the Artists view
  • (i) button to edit the metadata of the currently playing song from Now Playing
  • Options to show or hide individual buttons in Now Playing
  • More typefaces: Avenir Next, Helvetica Neue, Georgia, Futura, Gill Sans, American Typewriter, and more
  • Alternative tile view for playlists
  • Option to prioritize the queue by highest-rated songs
  • Sort playlists by title, artist, album, rating, or manually
  • Option to import songs with a default rating
  • General design consistency improvements across panels, text, options, translations, theme collections, behavior, and readability (Statistics, Appearance, Library)

Bug fixes

  • Fixed: The Library panel didn't close after importing a backup
  • Fixed: Tapping a previously assigned playlist in the Add to Playlist panel didn't remove the assignment
  • Fixed: In the queue, some songs could be skipped and dropped out of rotation after being reordered
  • Fixed: Switching to gapless mode mid-song would stop playback after a few tracks
  • Fixed: The context menu option in playlists "Remove from this playlist" now replaces the old "Delete song," which used to delete the track from the library
  • Fixed: When importing music from a playlist, the import indicator was a spinner instead of a progress bar
  • Fixed: A bug where playing a playlist with shuffle on would play from the selected song but ignore the rest of the list
  • Fixed: Repeat-one (1) would play the track once and then pause instead of repeating it
  • Fixed: While searching for metadata and cover art, the "Searching" text would wrap to more than one line and make the panel flicker
  • Fixed: The miniplayer's Next button lit up orange when pressed while "Miniplayer uses theme colors" was off
  • Fixed: "Valoración" was renamed to "Calificación" (Rating) in the Spanish interface
  • Fixed: "Skipped" appeared twice in Statistics
  • Fixed: The prompt offering to import a backup wasn't showing after finishing a music import
  • Fixed: On the lock screen and Dynamic Island, the second word of the artist name appeared in lowercase when "capitalize first word only" was enabled in appearance preferences

Enjoy!
— L.D.
