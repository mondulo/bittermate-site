Canvases

Four canvases for the same content.

Map, Board, Mural and Calendar show the same notes in four ways. Backgrounds have Cork, Granite, Wood or Marble textures.

  • Map
  • Board
  • Mural
  • Calendar
Notes

Each note, with what it needs.

Tags, colored pushpins, photos and voice notes. Capture from any app with the Share menu.

Places

Notes tied to a place.

Geolocation and map. The proximity radar shows what’s nearby, and content can expire when it’s no longer needed.

  • Geolocation and map
  • Proximity radar
  • Content expiry
Features

Everything it includes.

Canvases
  • Map, Board, Mural and Calendar
  • Cork, Granite, Wood and Marble textures
  • Pin color dot in Board and Mural
  • Redesigned note views, with more writing space
  • Improvements to the iPad sidebar
Notes
  • Rich text: three title sizes, bold, italic, underline, bullets and any color
  • Tags, colored pushpins, photos and voice notes
  • Capture from any app with the Share menu
  • Pin a note from inside it
  • If a note has a photo but no text, only the photo is shown
  • Export all of a note’s images to Files
  • Current-year tag on new notes (can be turned off)
  • Tags with no notes are removed automatically
Places
  • Geolocation and map
  • Proximity radar
  • With two photos at different coordinates, you choose which to use on the note’s map
  • Share a location with a QR code
Expiry
  • Content expiry
  • Retroactive automatic expiry for all notes that don’t have one
  • The Expiring view shows the soonest first
Collectible cards
  • Each version is named after a remote place and has its own card
Backup and iCloud
  • Import and export of backups
  • iCloud sync across devices
  • New alternative icons
